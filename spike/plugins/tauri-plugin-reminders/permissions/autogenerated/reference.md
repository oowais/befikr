## Default Permission

Allows all reminders commands (spike).

#### This default permission set includes the following:

- `allow-schedule`
- `allow-cancel`
- `allow-status`
- `allow-request-notifications`
- `allow-open-exact-alarm-settings`
- `allow-open-battery-settings`
- `allow-take-launch-route`
